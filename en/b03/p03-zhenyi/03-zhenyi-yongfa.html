Chapter Three · The True Intention · 真意用法

How to Use the True Intention

How to use the true intention — the outer Yellow Dame moves to gather the medicine, the inner Yellow Dame is still to refine the elixir; whether or not one enters the obscure, always let the Original Spirit issue as the true intention and preside

About This Chapter

The previous section explained that the true intention divides into wu and ji; this section explains concretely how to use it:

  1. The key to learning the Way is simply to take the true intention as master. “True earth seizes true lead; with true lead subdue true mercury” — use the true intention to seize the Prior Heaven true yang breath, then use the true yang breath to subdue the restless mind-spirit; the three families unite into one, and the Way is here.
  2. There are two ways of using the intention:
    • The intention in movement (the outer Yellow Dame): it brings the two families together, and has no fixed position. If one does not know how to gather the medicine in movement, the Prior Heaven original breath cannot be summoned back.
    • The intention in stillness (the inner Yellow Dame): it carries the news of that moment, and has a fixed position. If one does not know how to refine the elixir in stillness, the Prior Heaven original breath cannot condense into an embryo.
  3. The key in every sitting: whether or not one has entered the obscure, always let the Original Spirit issue as the true intention and preside; when true yang arises, also let the Original Spirit preside over it and transform it — beyond this, mix in not a bit of opinion and add not a bit of intention; this is the supreme vehicle of cultivation.

Qiu Ling’s note: the ancients called the true intention the “matchmaker” and the “Yellow Dame”; wu-ji is its code name, and “husband and wife” are code names for Kan and Li, spirit and breath. The true intention presides over and directs the whole process of practice: when movement is needed, it moves in response; when stillness is needed, it is still in response; without the true intention, one falls into dull emptiness.

Original Text and Translation

§1
Original (Chinese)

学道之要，惟以真意为主。所谓真土擒真铅，以真铅制真汞，三家合一，两性交欢，斯道在是矣！然用意之法有二：一为动时之意；一为静时之意。丹书所谓外黄婆者，通家之和好，故无位而动。若不知动以采药，先天元气如何招摄得回来？此动中之用意也。内黄婆者，传一时之音信，故有位而静。苟不知静以炼丹，先天元气又如何凝结成胎？此静中之用意也。

The key to learning the Way is simply to take the true intention as master. What is called “true earth seizes true lead; with true lead subdue true mercury” — use true earth (the true intention) to seize true lead (the Prior Heaven true yang breath), then use true lead to subdue true mercury (the restless, wavering mind-spirit) — and so the three families unite into one (the three families of essence, breath and spirit, as the alchemists say, merge into one family), the two natures rejoice together (the two natures of yin and yang unite), and the Way is here! But there are two methods of using the intention: one is the intention in movement, the other the intention in stillness. The “outer Yellow Dame” of which the alchemical books speak goes between the two families (Kan and Li, spirit and breath) to bring them into harmony, and so has no fixed position, and moves. If one does not know how to gather the medicine in movement, how could the Prior Heaven original breath be summoned back and taken in? This is the use of the intention in movement. The “inner Yellow Dame” carries the news of that moment (when true yang stirs), and so has a fixed position, and is still. If one does not know how to refine the elixir in stillness, how could the Prior Heaven original breath condense into an embryo? This is the use of the intention in stillness.

§2
Original (Chinese)

每静坐一次，管他杳冥不杳冥，总将我元神发为真意以为之主；即至杳冥久久，真阳发生，我亦以元神主宰之而变化之，此外不参一见，不加一意，方是上上乘修炼之道。

In every sitting, whether or not one has entered the obscure, always let my Original Spirit issue as the true intention to preside; when the obscure has lasted a long time and true yang arises, I also let the Original Spirit preside over it and transform it; beyond this, mix in not a bit of opinion and add not a bit of intention — only this is the supreme vehicle of cultivation.

Qiu Ling's noteon §1–§2
Original note (Chinese)

古云：“真意为媒妁”，《悟真篇》中说：“本因戊己为媒妁，遂使夫妻镇日欢。”戊己即真意的代号，亦名黄婆。夫妻即坎离、神气的代号。真意作为媒妁或黄婆，主宰和指挥着练功的整个过程，须动者动而应之，须静者静而应之。若无真意，则堕于顽空。

The ancients said: “The true intention is the matchmaker.” (The true intention is the go-between who brings spirit and breath together.) The Awakening to Reality says: “Originally because wu-ji acts as matchmaker, husband and wife rejoice all day long.” “Wu-ji” is the code name for the true intention, also called the “Yellow Dame”; “husband and wife” are the code names for Kan and Li, spirit and breath. The true intention, as matchmaker or Yellow Dame, presides over and directs the whole process of practice: when movement is needed, it moves in response; when stillness is needed, it is still in response. Without the true intention, one falls into dull emptiness.

Key Terms

  • True earth: the true intention; see True Intention.
  • True lead, true mercury: true lead is the Prior Heaven true yang breath, true mercury the restless mind-spirit; see Lead and Mercury.
  • True earth seizes true lead; with true lead subdue true mercury: seize the true yang breath with the true intention, then subdue the mind-spirit with the true yang breath.
  • The three families uniting into one: the alchemists take essence, breath and spirit as three families, merging into one.
  • The two natures rejoicing together: the two natures of yin and yang uniting.
  • Yellow Dame: a code name for the true intention, acting as go-between for Kan and Li, spirit and breath.
  • Outer Yellow Dame: the intention in movement, with no fixed position, used to gather the medicine.
  • Inner Yellow Dame: the intention in stillness, with a fixed position, used to refine the elixir and condense the embryo.
  • Matchmaker: a go-between, a metaphor for the true intention bringing spirit and breath together.
  • Husband and wife: code names for Kan and Li, spirit and breath; see conjunction of Kan and Li.

Putting It into Practice

  1. Using the intention in movement is gathering: when true yang stirs, the true intention comes forth to gather it in and summon it back.
  2. Using the intention in stillness is nourishing: in settled concentration, the true intention guards and nourishes warmly, letting the original breath condense.
  3. In every sitting, let the true intention preside. Whether or not you enter the obscure today, let the Original Spirit issue as the true intention and preside.
  4. Beyond presiding, add nothing else. Mix in no opinion, add no intention — presiding does not mean exerting force.

Translator's Notes

  1. The original text of this section is in two paragraphs; the original book does not give the source.
  2. “Goes between the two families to bring them into harmony” (通家之和好): tong, to communicate; jia, the two families of Kan and Li. The outer Yellow Dame goes back and forth between the two families as go-between.
